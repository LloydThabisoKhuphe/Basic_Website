CampusMobi

Team Project — Campus Assistant Application

A web-based campus assistant application designed to help university students access campus services, manage their academic information, and navigate their campus more efficiently.

Team Development Project

Project Overview

CampusMobi is a campus assistant application designed to provide students with convenient access to important university services and information from one platform.

The application brings together features such as digital student identification, campus navigation, academic schedules, notifications, and campus services.

Project Objectives

The main objective of CampusMobi is to create a centralized digital platform that improves the student experience on campus.

User Authentication

Allows students to securely log into the application and access their personal information and services.

Student Dashboard

Provides a central location where students can access the different features available within CampusMobi.

Virtual Student Card

Provides students with a digital student card containing their details and a QR code for identification and access to campus facilities.

Academic Calendar

Allows students to view their academic schedule and manage important events such as classes and activities.

Notifications

Provides reminders about upcoming classes and other important academic events.

Campus Navigation

Provides students with a campus map and information about locations such as lecture halls, libraries and administrative offices.

Project Scope

What's Included:

  • User registration and authentication
  • Student and staff virtual identification cards
  • Campus map and navigation
  • Academic calendar and scheduling
  • Schedule-based notifications
  • Campus services and information
  • Student communication and forum features
  • User profiles and account management
