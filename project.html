CampusMobi

web-based campus assistant application designed for students at IWS

Project Overview

This app allows users to view their cards (staff/student) for Accessing so facilities e.g library , study centre and etc , including with the navigation within the campus showing you a map , and it also allows users to uterlize Campus services

Project Objectives

Key Functions:

  • User AuthenticationStudents can log into the system securely and access their personal dashboard.
  • Dashboard A central dashboard allows users to easily navigate between all system features.
  • Virtual Student Card A digital student card is provided within the system. It displays student details along with a QR code that can be used for identification purposes when accessing campus facilities.
  • Calendar The system provides a calendar where students can: View their academic schedule, Manage events such as classes
  • Schedule Notifications Notifications are generated based on calendar events to: Remind students of upcoming classes, Help students stay organized
  • Campus Maps Students can view a simplified campus map or list of locations, including: Lecture halls, Library, Administration offices, Selecting a location shows basic information to assist with navigation.

Project Scope

What's Included:

  • User registration and authentication system
  • Course creation and management module
  • Assignment submission and grading system
  • Discussion forums and messaging features
  • Progress tracking and reporting dashboards
  • Administrative tools for system management

Project Timeline

Development Phases:

  1. Phase 1 (Week 1-2): Planning and Design - Requirements analysis and UI/UX design
  2. Phase 2 (Week 3-4): Frontend Development - Build responsive user interfaces
  3. Phase 3 (Week 5-6): Backend Development - Create database and server logic
  4. Phase 4 (Week 7): Integration and Testing - Combine frontend and backend components
  5. Phase 5 (Week 8): Deployment and Documentation - Launch and create user guides

Technologies Used

  • Frontend: HTML5, CSS3, JavaScript, React.js
  • Backend: Node.js, Express.js
  • Database: MongoDB
  • Authentication: JWT (JSON Web Tokens)
  • Version Control: Git & GitHub
  • Deployment: Vesel
